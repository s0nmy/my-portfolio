# MVPの範囲と今後の拡張

最初のリリース（MVP）では、作品紹介、プロフィール、外部SNSへの導線だけを提供する。このページは、MVPに含めないものと、必要になったときの方針をまとめる。読み手は、機能の追加を検討する開発者とAIエージェントを想定している。

## MVPに含めないもの

次の機能は、必要になった時点で追加を検討する。

- お問い合わせフォーム
- サーバー側のAPIと動的な処理
- Turnstile
- データベース
- 会員機能と管理画面
- R2による画像・動画の配信

## 将来の拡張

### お問い合わせフォーム

訪問者がサイトから連絡できるようにする機能。メール送信サービスへは、ブラウザから直接つながず、Cloudflare Workersを経由する。

- 導入時の構成
  - Cloudflare Workersに `/api/contact` を実装する
  - Turnstile（ボット対策）を、Workers側で検証する
  - 検証が通ったときだけ、メール送信サービスへ渡す
- APIキーは、Cloudflareのsecretで管理する

### R2

画像や動画を置くCloudflareのストレージ。作品の画像や動画が増えて、リポジトリでの管理が重くなったら導入する。

- 公開先は、`assets.example.com` のような独自サブドメインにする
- 開発用の `r2.dev` のURLは、本番の配信に使わない
