# ワークフロー定義

リポジトリ内のワークフロー手順はこのディレクトリを正本とします。

- [Pull Requestを作成する](create-pull-request/README.md)
- [ブランチ名を提案する](suggest-branch-name/README.md)

`commands/`はCodexのコマンド入口、`.claude/commands/`はClaude Codeのスラッシュコマンド入口、`.AGENTS/skills/`はCodexのスキル入口です。各入口には手順の複製を置かず、該当するワークフロー定義へ案内してください。実際の手順はこのディレクトリで更新します。
